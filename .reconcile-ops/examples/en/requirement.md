# Requirement: Todo Web App

## Context

The client wants a simple web app for managing personal todo items. The first delivery should focus on basic task tracking without account or team features.

## Client Wants

- Users can create todo items with a short title.
- Users can mark todo items as completed.
- Users can delete todo items that are no longer needed.
- Todo items remain available after refreshing the browser.

## Client Does Not Want

- Account registration is not required for the first delivery.
- Team sharing is not required for the first delivery.
- Due dates, reminders, and calendar integration are not required for the first delivery.

## Constraints

- The app should run in a browser.
- The first delivery should prioritize simple usage over advanced task management.
