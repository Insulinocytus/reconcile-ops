# 要件: ToDo Web アプリ

## 背景

クライアントは、個人の ToDo 項目を管理するためのシンプルな Web アプリを求めている。初回提供では、アカウント機能やチーム機能を含めず、基本的なタスク管理に重点を置く。

## クライアントが求めていること

- ユーザーは短いタイトルで ToDo 項目を作成できる。
- ユーザーは ToDo 項目を完了済みにできる。
- ユーザーは不要になった ToDo 項目を削除できる。
- ブラウザを再読み込みした後も ToDo 項目を引き続き利用できる。

## クライアントが求めていないこと

- 初回提供では、アカウント登録は不要。
- 初回提供では、チーム共有は不要。
- 初回提供では、期限、リマインダー、カレンダー連携は不要。

## 制約

- アプリはブラウザで動作すること。
- 初回提供では、高度なタスク管理よりもシンプルな使いやすさを優先すること。
