# 规格说明：认证登录

## 来源文档

- [基础待办事项管理](../../docs/goals/G-000001.md)
- [待办事项 Web 应用](../../docs/requirements/todo-web-app.md)

## 目的

在实现前定义登录行为的基础设计。本规格说明聚焦于支持认证入口、校验、会话创建和面向用户的错误提示所需的代码级设计。

## 行为

- 用户从登录表单提交邮箱和密码。
- 系统在调用认证服务前，校验两个字段均已填写。
- 认证服务验证凭证，并在凭证有效时返回已认证会话。
- 凭证无效时返回通用登录错误。
- 登录成功后将用户重定向到待办事项列表。

## 边界

- 登录流程负责表单校验、认证请求处理、会话创建和重定向行为。
- 登录流程不负责注册、密码重置、团队成员关系或账号管理。

## 接口

- `POST /login`
  - 输入：邮箱和密码。
  - 成功：已认证会话和重定向目标。
  - 失败：通用认证错误。

## 数据契约

- 登录输入要求邮箱和密码均非空。
- 会话契约必须标识已认证用户，且不得暴露密码数据。

## 校验规则

- 邮箱为必填项。
- 密码为必填项。
- 认证失败不得透露该邮箱是否存在。

## 错误处理

- 缺少字段时显示字段级校验错误。
- 凭证无效时显示一条通用登录失败消息。
- 认证服务发生意外错误时返回安全的通用错误，并应能通过应用日志观测到。

## 验证方法

- 验证缺少邮箱和密码时会产生校验错误。
- 验证凭证无效时不会创建会话。
- 验证凭证有效时会创建会话，并重定向到待办事项列表。
- 验证登录错误不会透露账号是否存在。
