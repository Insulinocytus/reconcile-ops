# 需求：待办事项 Web 应用

## 背景

客户希望构建一个用于管理个人待办事项的简单 Web 应用。首个交付版本应聚焦于基础任务跟踪，不包含账号或团队功能。

## 客户希望

- 用户可以使用简短标题创建待办事项。
- 用户可以将待办事项标记为已完成。
- 用户可以删除不再需要的待办事项。
- 刷新浏览器后，待办事项仍然可用。

## 客户不需要

- 首个交付版本不需要账号注册。
- 首个交付版本不需要团队共享。
- 首个交付版本不需要截止日期、提醒和日历集成。

## 约束

- 应用应在浏览器中运行。
- 首个交付版本应优先保证简单易用，而不是高级任务管理能力。
